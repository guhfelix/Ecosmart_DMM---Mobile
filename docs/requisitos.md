# Requisitos do MVP

## EcoSmart Cidadão

- Registrar descarte.
- Consultar histórico.
- Consultar dicas educativas.
- Consultar pontos de coleta.

## EcoSmart Empresa/Catador

- Visualizar descartes cadastrados.
- Filtrar por tipo de resíduo.
- Marcar descarte como coletado.

## EcoSmart Admin

- Cadastrar tipos de resíduos.
- Cadastrar pontos de coleta.
- Cadastrar dicas educativas.
- Visualizar registros gerais.
